# Project Rules & Guidelines

## Behavior on "continue" or "agy --continue"
- Whenever the user asks to "continue" or runs `agy --continue`, do **NOT** make modifications or execute tasks automatically.
- Always provide a concise, structured overview of the **Current State of the Project**:
  1. What components are completed and verified.
  2. What components are pending in the backlog.
  3. Git working tree and environment status.
- Wait for explicit user confirmation or instructions before proceeding with any implementation or changes.
